Как работать с CallReview

Внутренний инструмент оценки звонков: чек-листы, оценки, аналитика и калибровка. Ниже — пошаговое руководство по каждому разделу.

С чего начать

Работа в сервисе строится вокруг четырёх разделов в верхнем меню:

Чек-листы
Шаблоны оценки: блоки и критерии с весами. Создаются один раз, потом по ним оцениваются звонки.
Оценки
Заполнение чек-листа по конкретному звонку/сделке. Основная ежедневная работа.
Отчёты
Аналитика по сотрудникам, блокам, связь оценок с результатом сделки.
Калибровка
Сверка понимания чек-листа: несколько человек оценивают одну сделку и сравнивают ответы.
Типичный порядок: создать чек-лист → оценивать по нему звонки → смотреть отчёты → калибровать спорные оценки.

Чек-листы

Чек-лист — это шаблон оценки. Структура: Чек-лист → Блоки → Критерии. У каждого блока и критерия есть вес, из которого складывается итоговый балл.

1
Создание. Раздел Чек-листы → «Создать чек-лист». Задайте название и способ расчёта итога: взвешенный (критерии с бо́льшим весом влияют сильнее) или среднее.
2
Блоки и критерии. На странице редактирования добавляйте блоки (например «ЛПР-ность», «Боль и детализация»), внутри — критерии. У критерия можно указать вес и описание-подсказку.
3
Настройки. На вкладке настроек можно привязать чек-лист к отделам и посмотреть, кто и когда его создавал/менял.
4
Публикация / архив. Готовый чек-лист публикуется и становится доступен в форме оценки. Неактуальные — отправляйте в архив (обычно одновременно активны 2–3 чек-листа).
Создавать и редактировать чек-листы может любой пользователь — разграничения ролей нет.

Оценка звонка

Раздел Оценки → «Новая оценка».

1
Найдите сделку в Битрикс24. Поиск по ID сделки или имени оператора. После выбора автоматически подтянутся: сотрудник, отдел, дата звонка, ссылка на сделку, категория клиента и результат сделки.
2
Выберите чек-лист, по которому оцениваете.
3
Проставьте ответы по каждому критерию: Да Нет Н/П (не применимо — не влияет на балл). К любому критерию можно добавить комментарий (в т.ч. с флагом и таймкодом момента в звонке).
4
Сохраните. Две кнопки: Опубликовать — оценка попадёт в аналитику; Сохранить черновик — оценка сохранится, но не будет учитываться в отчётах, пока вы её не опубликуете.
Полезно знать
  • Дата звонка подставляется из Битрикс (дата презентации, а при её отсутствии — дата создания сделки) и остаётся редактируемой.
  • Дата оценки проставляется автоматически при сохранении.
  • Телефон — необязательное поле. Нужно, если по одной сделке было несколько звонков: телефон различает их.
  • Нельзя дважды опубликовать оценку одной и той же сделки по одному чек-листу — повтор сохранится как черновик с предупреждением.

Список оценок и фильтры

В разделе Оценки — все оценки с фильтрами и сортировкой.

  • Фильтры: сотрудник, отдел, чек-лист, оценщик, сделка, результат сделки, статус (опубликовано / черновик), период, отметка «на калибровке».
  • Сортировка — по клику на заголовок колонки (номер, сотрудник, отдел, дата, итог, результат); фильтры при этом сохраняются.
  • Результат сделки (Won / Lost / в работе) подтягивается из Битрикс автоматически — вручную вводить не нужно.
  • Оценку можно открыть, отредактировать, удалить, экспортировать в XLSX или отметить для калибровки.

Отчёты

Два отчёта, переключаются в шапке раздела Отчёты. В аналитику попадают только опубликованные оценки.

1. Общие показатели (/reports)
  • Тепловая карта — средние баллы сотрудников по блокам.
  • Корреляция — связь баллов блоков с результатом сделки.
  • По сотрудникам — Won / Lost / Win Rate по уровням выполнения.
  • Внизу: категория клиента vs оценка, оценка vs исход сделки, оценка vs скорость закрытия.
2. Результаты сотрудников (/reports/employee)
  • Расширенные фильтры: период звонка/оценки, отделы, сотрудники, чек-лист, кто оценивал, стадия сделки.
  • Настройки вида: проценты или баллы; разрез по группам или детально по критериям; показывать комментарии.
  • Сводная тепловая карта по сотрудникам + строка «Команда» и детализация по каждой оценке со ссылкой на сделку.
Отчёты выгружаются в XLSX с сохранением цветовой подсветки.

Калибровка

Калибровка нужна, чтобы сверить, одинаково ли разные люди понимают чек-лист. Несколько участников независимо оценивают одну и ту же сделку, затем ответы сравниваются с исходной оценкой.

1
Отметьте оценку для калибровки. На странице оценки — кнопка «Отметить для калибровки». Такие оценки помечаются красной точкой в списке.
2
Создайте сессию. Раздел Калибровка → «Новая сессия»: название, дата, одна или несколько сделок (все по одному чек-листу) и участники.
3
Участники оценивают независимо. Каждый заполняет форму по сделке, не видя исходных ответов. Если у участника уже есть своя опубликованная оценка этой сделки — её можно подставить в форму одной кнопкой (и проверить перед сохранением).
4
Сравните. На странице сессии — матрица «сделки × участники» с % совпадения (цветная заливка: зелёный / жёлтый / красный). Кнопка «Сравнить оценки» открывает детальный разбор по критериям.
5
Разберите расхождения. По каждому несовпадению можно зафиксировать итоговый правильный ответ и пояснение. Когда закончили — закройте сессию.

Частые вопросы

Скорее всего, оценка сохранена как черновик. В аналитику попадают только опубликованные оценки. Откройте оценку и нажмите «Опубликовать».

По этой сделке и чек-листу уже есть опубликованная оценка. Чтобы оценить второй звонок по той же сделке — заполните поле Телефон, оно различает звонки.

Да — критерий выполнен, Нет — не выполнен (снижает балл), Н/П — критерий неприменим к этому звонку и не учитывается в расчёте.

Чтобы оценки были объективными: если два оценщика по одному звонку ставят разные ответы, значит критерий понимается по-разному. Калибровка выявляет такие расхождения и помогает договориться о едином понимании.
Остались вопросы по инструменту — обратитесь к руководителю ОПП.
